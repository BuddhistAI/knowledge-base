# Design documents

This folder holds the EGM design documents for changes to the knowledge base. Each BuddhistAI repo with pages that users see has the same folder (`docs/designs/`), and its `CLAUDE.md` sets it as the EGM artifact directory.

- One file per change: `<yyyy-mm-dd>-<slug>.md`, started from [TEMPLATE.md](TEMPLATE.md).
- The Elephant drafts it, the Goldfish review it (EGM writes its review reports next to it), and a person approves it in the pull request.
- `SITEMAP.md` lists the designs in this folder (EGM's own convention).

How to run a review: [Handbook: UX reviews with EGM](../../handbook/ux.md).
