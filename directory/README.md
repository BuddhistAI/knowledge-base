# Directory: Buddhist AI projects and datasets

This page lists Buddhist AI projects and datasets that we know of, from all traditions and languages. Use it to find tools and data for your Buddhist task, and to see who is already working on it.

- **Projects** are tools, apps, models and groups: translation, text libraries, OCR, speech, chatbots, agent skills, practice and research.
- **Datasets** are data you can download or use: benchmarks, texts, parallel translations, OCR images, speech and annotations.

Being listed does not mean we tested or recommend a project. To compare tools on the same test, see the [leaderboard](https://buddhistai.github.io/buddhist-benchmarks/).

> **Add or fix an entry.** [Suggest a project or dataset](https://github.com/BuddhistAI/knowledge-base/issues/new?template=add-to-directory.yml) by pasting a link, and a maintainer adds it. Or edit the lists yourself: [projects.yml](https://github.com/BuddhistAI/knowledge-base/edit/main/directory/projects.yml) and [datasets.yml](https://github.com/BuddhistAI/knowledge-base/edit/main/directory/datasets.yml). The ✎ next to each name opens that entry.

**How to read the tables.** "How open" says what you may do with it: an open license (for example MIT, Apache-2.0, CC0, CC-BY), non-commercial only (NC), free to use but closed source, or "license not stated" (ask the makers before you reuse it). "Last activity" is the latest change we saw on the project's code or data page, and "–" means we could not tell. All links were checked on 17 November 2026.
